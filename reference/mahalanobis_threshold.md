# Chi-squared threshold for the Mahalanobis test in latent space

Chi-squared threshold for the Mahalanobis test in latent space

## Usage

``` r
mahalanobis_threshold(df, alpha = 0.05)
```

## Arguments

- df:

  Latent space dimension (degrees of freedom)

- alpha:

  Significance level (default 0.05)

## Value

Numeric scalar threshold
