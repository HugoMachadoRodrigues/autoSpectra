# Predict with a Cubist + PCA bundle

Predict with a Cubist + PCA bundle

## Usage

``` r
predict_cubist_pca(bundle, X_new)
```

## Arguments

- bundle:

  List from
  [`load_cubist_pca()`](https://HugoMachadoRodrigues.github.io/autoSpectra/reference/load_cubist_pca.md)

- X_new:

  Preprocessed spectral matrix in the same band order as training

## Value

Numeric vector of predictions
