# Apply Standard Normal Variate (SNV) row-wise

Per Safanelli et al. 2025: SNV is the canonical OSSL preprocessing step,
selected through the SS4GG ring-trial experiment for its ability to
remove instrument-specific scaling and particle-size scattering effects.

## Usage

``` r
apply_snv(M)
```

## Arguments

- M:

  Numeric matrix

## Value

SNV-transformed matrix
